FUNCTIONS

从一张报告，到能讲清的病史

围绕「收得进、看得懂、带得走、不外传」设计的完整链路，全部功能都在本机完成。

拍照 / PDF，报告变数据

拍照、相册图或导入 PDF，本机 OCR 自动判断报告类型：化验单逐项填入数值、单位与参考区间并标出偏高偏低；影像类报告只提取「检查所见」与「诊断结论」。保存前可对照原图逐项核对、改错、补录。

原件永久留档 · 可缩放翻页

不想打字也能记

模板录入、随手文字、语音口述（说一句「血压 138 88」自动拆成结构化指标）、疾病与用药时间线等共 8 种入口。血压、血糖、体重、心率、血氧自动归入五大类档案，全局搜索一搜就到。

8 种录入入口

血压双线趋势

收缩压与舒张压两条曲线同屏，各有正常参考上下限虚线与每个采样点的数值，落在区间外的点直接标红。支持左右滑动与捏合缩放调整时间范围，下方列出最近 50 条明细，越界行单独着色。

滑动 / 缩放 · 最近 50 条

核心指标曲线

血压、血氧、体重、心率等指标各有独立曲线，同时显示参考值、参考上下限与逐点数值；最近记录表格中对超出参考线的整行加浅色背景，异常值加粗标红，一眼定位问题时段。

参考区间 · 逐点数值

就诊时，把手机递过去

「医生视图」一页汇总近 3 月关键异常、当前用药、疾病与用药时间线、过敏史与手术史；可切成大字号展示模式，或导出为多页 PDF 提前发给医生。摘要末页明确标注就诊参考声明。

大字号展示 · PDF 导出

一家人的档案互不干扰

多位家庭成员独立建档、一键切换；每位成员的指标、报告、疾病与用药记录彼此隔离。换手机时用备份包整体迁移，图片与 PDF 原件一起带走，导入后保持原有 ID 与关联关系。

多成员 · 备份迁移

隐私不是选项，是地基

无需注册登录、没有账号、没有云端。敏感字段由系统 Keystore 托管的 AES-256-GCM 密钥加密落盘，另有 PIN 码与指纹 / 面容应用锁。OCR 模型内置手机，语音识别不保存音频。

字段级加密 · 应用锁

导出全部数据为 PDF

文字记录与按时间线排列的图片报告、PDF 报告首页预览，可整理成一份完整 PDF；导出与导入备份包带进度提示和成功 / 失败状态，重操作在后台线程执行，不卡界面。

HOW IT WORKS

四步，把病历整理好

1

建档

给每位家庭成员建立独立档案，随时一键切换。

2

录入

PRIVACY BY DESIGN

你的健康数据，不出这部手机

应用采用纯本地架构：全部记录保存在本机数据库，源码中不包含任何网络请求代码。本应用已在 AndroidManifest 中移除 INTERNET 与 ACCESS_NETWORK_STATE 权限，系统层面无法发起任何网络连接；RECORD_AUDIO 用于系统语音识别（不保存音频），USE_BIOMETRIC 用于应用锁。

✓
